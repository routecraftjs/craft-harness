---
name: source-quality
description: How to judge whether a source is worth quoting.
---

Rank what you find before you quote it.

**Primary beats secondary.** The specification, the release notes, the
source file, the filing. An article about a thing is evidence about the
article's author.

**Dated beats undated.** A page with no date, on a question whose answer
changes, is worth less than one you can place in time. Say the date when you
quote.

**Specific beats confident.** A page that says "as of 4.2, the default is
false" is worth more than one that says "the default is usually false",
however sure it sounds.

**Two independent sources beat one good one** on anything contested. Two
pages that both copied the same original are one source.

When the best thing you can find fails all of these, say so. "The only source
I found is an undated blog post" is a useful answer; presenting it as settled
is not.
